# RoFront — World Conquest

Protótipo independente de estratégia territorial em tempo real, inspirado no ciclo de jogo de RoFront / Open Front. Feito com HTML, CSS e JavaScript puro, sem dependências externas.

## Jogar

Depois que o GitHub Pages estiver publicado, abra:

**https://nik0lasdev.github.io/roFront/**

## Como jogar

- Escolha uma nação e inicie a campanha.
- Clique em territórios neutros adjacentes à sua fronteira e use **Expandir**.
- Selecione territórios rivais adjacentes e use **Atacar** para tentar conquistá-los.
- Construa cidades para aumentar seu limite de tropas, fábricas para aumentar a renda e portos como infraestrutura.
- Administre tropas e ouro enquanto a IA rival expande e ataca.
- Controle **80% das terras** para vencer. Se perder todos os territórios, sua nação é eliminada.
- Use **Acelerar** para avançar o tempo.

## Controles

O jogo é jogado clicando no mapa e nos comandos da interface. A interface adapta-se a telas menores e suporta mouse e toque.

## Tecnologias

- HTML5 Canvas para o mapa interativo.
- CSS responsivo para a interface.
- JavaScript sem bibliotecas ou serviços externos.

## Escopo atual

Esta é uma recriação básica para navegador, em modo solo com mapa gerado proceduralmente e adversários controlados por IA. Não é uma cópia dos sistemas multiplayer, do mapa mundial real ou dos serviços internos do jogo original. RoFront é uma experiência do Roblox; este projeto é um protótipo de fã não oficial e não afiliado aos criadores originais.

## Desenvolvimento local

Abra `index.html` em um navegador moderno. Não é necessário instalar dependências ou iniciar um servidor.
