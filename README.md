## 🗺️ Sobre o jogo

Comece com uma pequena nação em um mapa gerado proceduralmente. Conquiste territórios próximos, fortaleça seu exército e administre os recursos enquanto nações rivais disputam o controle do mapa.

### Recursos disponíveis

- **Mapa interativo:** selecione territórios e observe as fronteiras das nações.
- **Expansão territorial:** ocupe terras neutras conectadas ao seu território.
- **Combate:** envie tropas para atacar territórios rivais adjacentes.
- **Economia:** acumule ouro e receba renda ao longo da partida.
- **Construções:** desenvolva cidades, fábricas e portos.
- **Nações rivais:** adversários controlados por IA expandem e podem atacar suas fronteiras.
- **Condição de vitória:** domine 80% das terras para vencer.
- **Interface responsiva:** jogue em computadores e telas menores.

## 🕹️ Como jogar

1. Abra o [jogo no navegador](https://nik0lasdev.github.io/roFront/).
2. Escolha uma nação na tela inicial e clique em **Iniciar campanha**.
3. Clique em um território no mapa para selecioná-lo.
4. Para ocupar uma terra neutra adjacente à sua fronteira, use **Expandir**.
5. Para tentar conquistar uma terra rival adjacente, selecione-a e use **Atacar**. Mantenha tropas suficientes para não deixar suas fronteiras vulneráveis.
6. Invista seu ouro em cidades e fábricas para fortalecer sua nação.
7. Use **Acelerar** para avançar o tempo mais rapidamente.
8. Continue expandindo até controlar **80% do mapa**.

### 💡 Dicas para iniciantes

- Expanda a partir de territórios que já controla: terras isoladas não podem ser ocupadas diretamente.
- Observe o número de tropas antes de iniciar um ataque.
- Equilibre expansão, defesa e economia.
- Uma derrota acontece se você perder todos os seus territórios.

## 🧩 Sobre esta versão

Esta é uma **recriação independente e básica**, feita para testar o ciclo central de conquista em um navegador. Ela ainda não reproduz todos os sistemas, mapas, modos multiplayer ou funcionalidades do jogo original.

RoFront é uma experiência associada ao Roblox. Este projeto é um protótipo de fã, não oficial e sem afiliação com os criadores do jogo original.

## 🛠️ Tecnologias

- HTML5 e Canvas para desenhar o mapa.
- CSS para interface e adaptação a diferentes telas.
- JavaScript puro para as regras de jogo e a IA.
- GitHub Pages para hospedagem estática.

Não são necessárias bibliotecas externas, instalação de pacotes ou servidor de aplicação.
